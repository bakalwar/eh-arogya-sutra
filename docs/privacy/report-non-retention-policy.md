# Report non-retention policy

Original reports and patient photographs must **not** be stored permanently.

Prohibited persistence includes PDF, JPG/JPEG, PNG, report/patient/clinical images, thumbnails, preview copies, OCR source images, base64 content, browser persistent cache, application backups of originals, analytics payloads, and logs containing report content.

After processing, preserve only safe report type, processing timestamp, verified structured findings, doctor verification status, confidence, source category, processing engine version, deletion verification status, and safe non-identifying metadata.

Do not retain original filenames that contain patient identity — use ephemeral random processing IDs.
