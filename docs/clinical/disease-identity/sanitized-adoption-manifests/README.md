# Sanitized adoption manifests (control plane)

Canonical in-repository control plane for sanitized disease-identity adoption manifests.

- Filename pattern: `<adoption-id>.adoption.json`
- Kind: `EHAS2_SANITIZED_DISEASE_IDENTITY_ADOPTION_MANIFEST_V1`
- No real production adoption entries are committed in the tooling PR.
- Synthetic fixtures used by unit tests live under `packages/disease-identity/tests/fixtures/`.
