# Clinical interpretation validation (Phase 5C)

Reconstructed **non-prescription** interpretation only:

- Affected organ / system (ranked; truncation forbidden)  
- Prakriti / temperament / constitution (UNKNOWN / MIXED valid)  
- Polarity (POSITIVE / NEGATIVE / MIXED / UNKNOWN)  
- Safety / red-flag (high BP); **does not claim emergency treatment**  
- Doctor-supplied diagnosis = evidence only, never absolute truth  
- Image evidence present → flagged unsupported; not used for findings  
- Report findings contract present → processing `INACTIVE`; findings not claimed  

Every conclusion cites structured evidence. Unsupported defaults are not applied.
Renderer / preview cannot change clinical fingerprints (static preview labels only).
