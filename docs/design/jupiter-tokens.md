# Jupiter design tokens

Implemented in `packages/design-system` (`tokens.css` + `tokens.ts`).

Components should use **semantic CSS variables** (`--ehas2-bg-primary`, `--ehas2-text-primary`, `--ehas2-accent`, …) rather than scattering raw hex values.

Canonical palette constants also export from `@ehas2/design-system` for documentation/preview swatches only.

Includes spacing, radii, shadows, focus, touch targets (44px), content width, header/sidebar sizes, z-index, motion, safe areas, and breakpoint documentation.
