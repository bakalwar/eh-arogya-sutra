# Responsive layout

| Band | Width | Shell behavior |
|------|-------|----------------|
| Mobile | 320–599px | Single column, compact header, bottom nav, safe-area padding |
| Tablet | 600–1023px | Collapsible/horizontal tablet nav, adaptive content |
| Desktop | 1024px+ | Persistent sidebar + top header + centered main |

QA widths: 320, 360, 390, 430, 768, 1024, 1280, 1366, 1440, 1920.

Phone device frames are **not** rendered in the app.
