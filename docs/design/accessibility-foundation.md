# Accessibility foundation (Phase 1B)

- Skip-to-content link
- Main landmark (`#main-content`)
- `aria-current="page"` on navigation
- Visible `:focus-visible` rings via tokens
- Minimum 44×44 touch targets
- Screen-reader-only text helper
- Status not color-only (text labels + SR text)
- `prefers-reduced-motion` disables skeleton motion
- Hindi via Noto Sans Devanagari
- Keyboard-operable links/buttons

Full WCAG audit is not claimed complete in Phase 1B.
