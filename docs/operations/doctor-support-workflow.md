# Doctor support workflow

## Standard path

`SUBMITTED` → `VALIDATED` → `ACCEPTED_PRIVATE` or `NEEDS_REVIEW` → `ASSIGNED` → `INVESTIGATING` → `WAITING_FOR_DOCTOR` → `RESOLVED` → `CLOSED` → `REOPENED` (when appropriate)

## Security-related path

`SUBMITTED` → `SECURITY_ESCALATED` → separate Super Admin / Security incident reference

Management Admin sees **safe escalation status** only — not sensitive attack details.

## Phase 2A-M

Workflow statuses exist as typed contracts. Live ticket assignment and messaging are **NOT_IMPLEMENTED**.
