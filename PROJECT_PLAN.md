# E.H. AROGYA SUTRA - Project Plan

## Goal

## Key Features (PWA Technology)
-   **Single Codebase**: Develop for Website + Android App + iOS App using PWA technology.

### User Panels
1.  **Admin Panel**:
    -   **Users**: System Controller
    -   **Main Tasks**: Manage rules, medicines, and doctors.
2.  **Doctor Panel**:
    -   **Users**: Primary User (Doctor)
    -   **Main Tasks**: Diagnosis, Prescription, Search Engine.
3.  **Patient Panel**:
    -   **Users**: Patient (View Only)
    -   **Main Tasks**: View prescriptions, receive reminders.
